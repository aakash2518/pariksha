═══════════════════════════════════════════════════════════
    DETAILED API BREAKDOWN
═══════════════════════════════════════════════════════════


API 1: FLASK FILE UPLOAD
────────────────────────────────────────────────────────────
Purpose:  Handle PDF uploads from browser
Input:    question_paper.pdf, answer_sheet.pdf
Output:   Saved files on server
Code:     request.files['question_paper']


API 2: PyPDF2
────────────────────────────────────────────────────────────
Purpose:  Extract text from PDF files
Input:    PDF file path
Output:   Plain text string
Code:     PyPDF2.PdfReader(file).pages[0].extract_text()

Example:
  Input:  question_paper.pdf
  Output: "Question 1: What is Python? (10 marks)"


API 3: GOOGLE GEMINI AI ⭐ (MAIN ENGINE)
────────────────────────────────────────────────────────────
Purpose:  Evaluate answers and generate feedback
Input:    Question text + Answer text
Output:   Marks, feedback, detailed evaluation

What it checks:
  1. ACCURACY (40%)
     - Is answer factually correct?
     - Concepts understood?
     - Right information?
  
  2. GRAMMAR (20%)
     - Spelling correct?
     - Sentence structure good?
     - Language quality?
  
  3. COMPLETENESS (30%)
     - All points covered?
     - Sufficient detail?
     - Nothing missing?
  
  4. RELEVANCE (10%)
     - Answers the question?
     - On topic?
     - Not off-track?

Example Prompt to AI:
  ┌──────────────────────────────────────────┐
  │ Question Paper:                          │
  │ Q1: What is Python? (10 marks)           │
  │                                          │
  │ Answer Sheet:                            │

  │                                          │
  │ Evaluate this answer comprehensively     │
  └──────────────────────────────────────────┘
